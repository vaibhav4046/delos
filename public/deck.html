Most AI tools today live in separate tabs and separate memories. You cannot draft an email in one place and ask a model in another to remember it. There is no surface where a voice command actually builds a working app while the same agent recalls last week's research.

The build

Two surfaces. One memory. Real work.

Website · delrio.vercel.app/os

Twenty four real apps in a window manager. Voice agent, memory browser, code app builder, browser, arena, calendar, schedule, notification center.
  • JUDGE DEMO pill plays a 60s narrated walkthrough
  • VibeCode streams a working five page app into DelCode
  • Arena races five models, judge picks winner
  • Voice agent with audio level ring, far field tuned

Chrome extension · /chrome-ext v3.1

Three tabs. Mission runs complex browser tasks. Cohort races five models. Memory mirrors the website by tenant id.
  • Perplexity style in page overlay with colored highlights
  • Live screenshots embedded after every step
  • Chain re plan up to three rounds for deep research
  • Endless conversation with browser action chaining

Same tenant id flows through both. Save a memory on the website, see it in the extension Memory tab within a poll cycle. Run a Mission in the extension, see it on the website.

Killer feature

The extension actually acts on the live page.

When the agent runs a multi step task, the extension injects an overlay into the active page. A floating banner narrates the steps. A colored outline pulses around the exact element being clicked or filled.

● click · blue ● fill · orange ● destructive · red ● navigate · green

This is what Perplexity Comet and Claude in Chrome do. We do the same with the standard Chrome scripting API, no content scripts running on every page. The overlay only mounts when a Mission runs and persists across page navigations through tabs.onUpdated.

Killer feature

Deep research the user actually wants.

Type a complex task. The planner produces navigate, scroll, extract, and answer steps. When the first plan ends without a real answer, chain re plan kicks in. Up to three rounds until the goal is hit.

Live test · "find best earbuds under 50 pounds"

1 navigate · google.com/search?q=best+wireless+earbuds+under+50+pounds
2 scroll · down 1500
3 extract · top 3 wireless earbuds with names, prices, features
4 answer · Anker Soundcore Liberty 2 Pro · £39.99 · 20h battery, Aukey · £29.99 · IPX7, Edifier TWS1 Pro · £44.99 · noise cancellation

Server enforces a final answer step for every research task. Client synthesizes from collected extracts when the planner leaves a placeholder. Never just "opened amazon".

Killer feature

Memory updates across both surfaces. Live.

HydraDB holds graph plus vector. Twelve seed memories auto write to any fresh tenant so the demo never starts empty.

Every Mission run, every Cohort verdict, every Voice store, every code build, every calendar event writes a typed memory with a source badge.

Same tenant id on the website and the extension. A run from one shows up in the other within thirty seconds. The Memory tab auto refreshes.

Killer feature

Voice that survives distance and silence.

Hardened against the usual Chrome SpeechRecognition failure modes.

Continuous on

Was off by default. Mic died after every pause. Now stays open for long, slow, multi sentence speech.

3 confidence alts

maxAlternatives bumped from 1 to 3. Picks the highest confidence alt. Free accent recovery.

Auto restart

no-speech, audio-capture, network, aborted all benign. Auto restart up to 30 times across a session. Transcript accumulates.

Live audio ring

Parallel mic stream feeds an AnalyserNode at 512 fftSize. Ring around the mic expands with voice. User sees mic is hot from across the room.

The brief

All four tracks covered.

Memory

Hydra graph plus vector under one tenant. Twelve seed entries. Recall fallback. Write guard. Cross surface sync between website and extension.

Tools

Real Chrome extension that clicks and fills the page. Five model arena with judge. MCP connectors. Streamed SSE codegen. Gmail, Notion, GitHub, Drive integrations.

Recovery

Six provider cascade. Deterministic domain cockpits when LLMs exhaust quota. Friendly UX for rate limits. Auto restart on STT silence. Graceful skip on chrome:// pages.

Adaptation

Chain re plan up to three rounds for complex tasks. Endless conversation that re engages browser actions on follow ups. Voice mic auto restarts up to thirty times. Mid run goal drift detection.
Two minute verify path

Open it. Watch it work.

  1. Open delrio.vercel.app/os?guest=1
  2. Press the JUDGE DEMO pill in the top bar. Watch sixty seconds of narrated agent action.
  3. Open the Memory app in the dock. Every step from the demo is already saved with a typed source badge.
  4. Install /chrome-ext (Developer mode, Load unpacked). Click the D icon.
  5. Mission tab: type "open hacker news and summarize the top five". Press RUN AGENT.
  6. Watch the in page overlay narrate steps on the actual Hacker News tab. Summary lands in the panel.
  7. Back to the website Memory app. The mission run from the extension is at the top with a browser-search badge.
