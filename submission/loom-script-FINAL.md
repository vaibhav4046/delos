# DelOS · five minute Loom script · killer cut

Read at a calm pace. Five sections, sixty seconds each. No buzzwords.
No phrases the demo cannot back up. Pause two beats between paragraphs
so the screen catches up.

Open these two before you hit record:
1. https://delrio.vercel.app/os?guest=1 in fullscreen
2. Chrome extension side panel pinned, Mission tab selected
3. A second browser tab on https://news.ycombinator.com ready

The script favors the things that look like nothing else in the bracket:
in page overlay, live memory sync, model cohort, chain re plan.

## 0 to 60 seconds. The hook. One tab, twenty four apps.

Hi. This is DelOS. It is a browser operating system for AI agents.
Everything you are about to see runs in one tab. No login. No card.
Guest mode is the demo.

You can see the dock at the bottom. Twenty four real apps. Voice
agent. Memory browser. Arena. App builder. Browser. Calendar. They
open into draggable windows.

Up top, four counters tick in real time. Agents running. Requests.
Tokens. Dollars. They are not fake. Every action you watch will
update them.

I am going to press the JUDGE DEMO pill. Sixty seconds. Five pillars.
Watch the explainer card.

(press JUDGE DEMO, narration plays)

## 60 to 120 seconds. Voice that builds, memory that updates.

Step one fired. Del Assistant drafted a Gmail message. Step two
created a Notion page. Step three listed real GitHub repos using the
public GitHub API. The voice agent did all three on its own.

Now look at step five. Memory Browser opens with the recall already
done. Every step the demo just ran is saved with a typed source
badge. Voice memory. Codegen. Arena. Calendar. That is HydraDB graph
plus vector under a tenant id. The same tenant id the Chrome
extension will use in a minute.

This is the differentiator. ChatGPT memory lives inside the model.
DelOS memory lives in HydraDB next to the OS. Every agent in every
tab can read the same store.

## 120 to 180 seconds. Chrome extension. Perplexity style overlay.

I am switching to the Chrome extension. Same brand. Same D logo.
Three tabs. Mission. Cohort. Memory. Mission is the unified agent.

I have Hacker News open in another tab. I type "open hacker news and
summarize the top five front page items". Press RUN AGENT.

Watch the page itself, not the side panel. A floating banner appears
at the top right of the Hacker News tab. It says "DelOS one of six
navigate". Then it says "two of six click". A colored outline pulses
around the exact link the agent is about to click. Blue for click.
Orange for fill. Green for navigate.

This is what Perplexity Comet and Claude in Chrome do. We do the
same. The extension is acting on the live page in front of you, not
on a screenshot in a sidebar.

A screenshot of each step lands back in the side panel so you have a
visual trace.

## 180 to 240 seconds. Complex task. Endless conversation.

Now the killer feature. I am giving it a research task that needs
multiple browse rounds. I type "research the top three wireless
earbuds under two hundred dollars for twenty twenty five and rank
them".

The agent plans, navigates, scrolls, extracts. When the first plan
finishes and the goal is not yet answered, chain re plan kicks in
automatically. Up to three rounds. The agent keeps going.

It returns three ranked picks with reasoning.

Now watch this. The conversation row at the bottom is enabled. I type
"what about noise cancellation on the second pick". The agent has the
prior context. It either re engages the browser if a new search is
needed, or answers from context with a follow up tag.

This is the endless conversation. The mic field on the website goes
in. The Chrome extension's Mission tab does the actual browser work.
Both surfaces share the same memory.

## 240 to 300 seconds. Memory across surfaces. The closer.

Back to the website. I open the Memory app. The mission run from the
extension is at the top of the list. Source badge says browser
search. Tagged extension and browser-search. The summary I just got
is right there.

The same tenant id flows through every component. Voice writes a
fact, the cohort verdict joins it, the extension's browse run lands
alongside, the next prompt picks the context up without re asking.

That is the whole story in five minutes. One tab on the website.
Three tabs in the extension. Twenty four apps in the OS. Five model
cohort with judge scoring. Voice that survives distance and silence.
Browser control with the same colored overlay Perplexity uses. Memory
that updates across both surfaces in seconds.

## Recording tips

- Speak slow. Pause two beats between paragraphs. Hide the browser
  toolbar with F11. Mute notifications.
- Record at 1080p. Keep the screen at 100 percent zoom. Numbers and
  badges are readable, dense UI looks crisp.
- If a provider quota trips, the agent falls back automatically.
  Just say "the cascade handed off to the next provider" and keep
  going. It is a feature, not a stumble.
- If the in page overlay does not show on a first attempt, refresh
  the target tab once. The chrome.scripting boot is idempotent.
- If the mic refuses, the Mission text input under the mic accepts
  the same text. The intent parser fires either way.
